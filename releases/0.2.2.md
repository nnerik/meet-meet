# Meet Meet 0.2.2

For **Apple silicon Macs running macOS 26 or newer**.

## What's new

- Turn off **Countdown during meetings** in **Settings → General** to count
  upward from meeting start as `m:ss` instead of counting toward the end.
  Keep the elapsed-time HUD visible for 0–10 minutes, default 3; zero hides it
  immediately at start. Countdown toward the end remains enabled by default.
- All timer settings now accept zero. Set a visual cue to zero minutes to show
  it at meeting start or end. At-end visual cues stay open until dismissed.

## Install or update

Download **MeetMeet-0.2.2-arm64.dmg**, open it, and drag **MeetMeet.app** to
Applications. Quit an older copy before replacing it, then launch the replacement.

**This build is ad-hoc signed, not Developer ID signed or Apple-notarized.**
macOS may block first launch. After trying to open it, use **System Settings →
Privacy & Security → Open Anyway** only if you trust the download. Managed Macs
may prohibit overrides. Do not disable Gatekeeper.

Settings should remain saved, but calendar access and launch-at-login approval
may need to be granted again. Updates are manual; there is no automatic updater.
See the [installation and update guide](https://github.com/nnerik/meet-meet/blob/v0.2.2/docs/installation.md).
The matching SHA-256 asset checks download integrity, not publisher identity.
