# Meet Meet 0.1.0

First release for **Apple silicon Macs running macOS 26 or newer**.

## Features

- Read-only calendar access with explicit calendar selection.
- Menu bar summaries and a draggable lower-right countdown HUD.
- Upcoming and ongoing countdowns, title reveal, scrolling and final-minute pulse.
- Theme-aware final splash cue, enabled one minute before meetings by default.
- Optional start/end sounds with bundled and system sound choices.
- Pause for Today, occurrence/series hiding, and temporary countdown suppression.
- Saved settings and opt-in launch at login.

## Install

Download **MeetMeet-0.1.0-arm64.dmg**, open it, and drag the app to Applications.
Quit an older copy before replacing it. The app lives in the menu bar, not the Dock.

**This build is ad-hoc signed and is not Apple-notarized.** macOS may block its
first launch. After trying to open it, use **System Settings → Privacy & Security
→ Open Anyway**, if you trust this download. Managed Macs may prohibit overrides.
Do not disable Gatekeeper. Calendar access may need to be granted again after
updates; settings should remain saved. There is no automatic updater.

See [installation and update instructions](https://github.com/nnerik/meet-meet/blob/v0.1.0/docs/installation.md).
The matching SHA-256 asset can be used to check download integrity.

## Known limitations

- No Intel support or support for macOS versions before 26.
- Spaces/full-screen presentation and sounds are best-effort within macOS rules.
- Calendar-provider identity changes may require hiding a meeting again.
- Packaging checks do not replace real-world testing of Gatekeeper, calendar
  permission retention, login registration, or every display/accessibility setup.
